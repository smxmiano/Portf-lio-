# Sabrina Maximiano Portfolio — V2

Static HTML/CSS portfolio redesigned for clearer navigation and usability.

## Upload to GitHub
Upload the entire folder contents preserving the `cases/` folder:
- `index.html`
- `styles.css`
- `cases/help-center.html`
- `cases/pulse.html`
- `cases/fleury.html`

No JavaScript is required in this version.

## Deploy
Import the GitHub repository into Vercel. The project can be deployed as a static site with no build command.
